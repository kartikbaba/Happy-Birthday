# 💕 Birthday Website — Setup Guide

## How to Replace Dummy Content

### 📸 Photos
Replace the placeholder images by adding your real photos to the `images/` folder with these names:

| File Name | Used In |
|---|---|
| `photo1.jpg` | Timeline — Chapter 1 (The Day We Met) |
| `photo2.jpg` | Timeline — Chapter 2 (First Adventures) |
| `photo3.jpg` | Timeline — Chapter 4 (Growing Together) |
| `photo4.jpg` | Timeline — Chapter 5 (Laughter) |
| `gallery1.jpg` | Gallery grid (tall item) |
| `gallery2.jpg` | Gallery grid |
| `gallery3.jpg` | Gallery grid |
| `gallery4.jpg` | Gallery grid (wide item) |
| `gallery5.jpg` | Gallery grid |
| `gallery6.jpg` | Gallery grid |
| `thumb1.jpg` | Video poster thumbnail |
| `thumb2.jpg` | Video poster thumbnail |
| `final-thumb.jpg` | Final video section poster |

> 💡 **Tip**: Any common image format works (.jpg, .jpeg, .png, .webp). Just keep the filenames the same!

---

### 🎬 Videos
Replace the placeholder videos by adding your video files to the `videos/` folder:

| File Name | Used In |
|---|---|
| `memory1.mp4` | Timeline — Chapter 3 (Quiet Moments) |
| `memory2.mp4` | Timeline — Chapter 6 (Little Things) |
| `special-message.mp4` | Final special message section |

> 💡 **Tip**: `.mp4` format works best for all browsers. You can also edit the HTML to link to YouTube/Google Drive videos using `<iframe>` if you prefer.

---

### ✍️ Text Content
Open `index.html` in any text editor (Notepad, VS Code, etc.) and find the paragraphs you want to edit. Look for the `<p>` tags inside each `.timeline-content` div and replace the text with your own memories and words.

Also edit:
- **Her name** in the hero title (find `My Love` in `index.html`)
- **Letter content** in the `.letter-body` section
- **Your signature** in `.letter-sign`

---

### 🌐 Opening the Website
Simply double-click `index.html` to open it in any browser. No server needed!

If you want to share it online, upload the entire folder (keeping the folder structure intact) to any free hosting like:
- [GitHub Pages](https://pages.github.com/)
- [Netlify Drop](https://app.netlify.com/drop) — just drag the folder!
- [Vercel](https://vercel.com/)
